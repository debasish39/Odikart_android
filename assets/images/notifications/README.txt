OdiKart Notification UI Assets

Contents
- banners/: promotional/order banner crops
- icons/: circular notification category icon crops
- thumbnails/: small notification card image crops
- illustrations/: empty state and notification illustrations
- decorative/: supporting decorative artwork
- notification-assets-reference-sheet.png: original complete asset sheet

Important
These PNGs are crops from one generated reference sheet, not original vector/source artwork. Some crops may include a little background padding and are suitable as visual placeholders. Check the crops in your app before shipping. For scalable category icons, prefer lucide-react-native icons.

Suggested React Native use
Place the folders under your app's assets/notifications/ directory and import the specific PNGs with require().
